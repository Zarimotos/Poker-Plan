# Спецификация импорта задач из CSV

**Задача:** PRE-01 — Определить формат данных задач для импорта из CSV  
**Владелец:** Системный аналитик  
**Связанные задачи:** S1-02 «Импорт задач из CSV с предпросмотром и подтверждением»  
**Статус:** Черновик для согласования  

## 1. Цель

Определить единый формат CSV-файла для импорта задач в Planning Poker, правила его валидации, обработки ошибок и преобразования данных во внутреннюю модель `Task`.

Спецификация является основой для реализации S1-02: Host выбирает CSV, видит список распознанных задач до подтверждения, а после подтверждения задачи сохраняются в серверной очереди.

**Вне объёма PRE-01:**

- прямое подключение к YouTrack;
- импорт Excel;
- редактирование задач после импорта;
- автоматическая двусторонняя синхронизация с YouTrack.

## 2. Требования к файлу

| Параметр | Значение |
|---|---|
| Формат | CSV |
| Расширение | `.csv` |
| Кодировка | UTF-8, желательно с BOM |
| Разделитель полей | `,` |
| Разделитель значений в multi-value полях | `;` |
| Экранирование | Двойные кавычки `"` |
| Кавычка внутри значения | Удваивается: `""` |
| Переносы строк | Допустимы внутри значений, заключённых в кавычки |
| Первая строка | Обязательная строка заголовков |
| Регистр заголовков | Точное совпадение |
| Пробелы в заголовках | Обрезаются по краям |
| Пустые строки | Игнорируются |
| Минимальное количество задач | 1 |
| Максимальное количество задач | 200 — требуется согласовать |
| Максимальный размер файла | 2 МБ — требуется согласовать |

## 3. Структура CSV

### 3.1. Обязательные колонки

| Колонка CSV | Поле `Task` | Тип | Обязательность | Ограничения |
|---|---|---|---|---|
| `ID задачи` | `externalId` | string | Да | Непустая строка, максимум 50 символов, уникальна в пределах файла |
| `Заголовок` | `title` | string | Да | 1–200 символов после trim |
| `Описание` | `description` | text | Да | 1–10 000 символов, переносы строк разрешены |
| `Ссылка YouTrack` | `youtrackUrl` | URL | Да | Валидный `http://` или `https://` URL, максимум 2 048 символов |
| `Компоненты` | `components` | string[] | Да | Непустой список из справочника |
| `Задетые сценарии` | `affectedScenarios` | string[] | Да | Непустой список из справочника |

### 3.2. Необязательные колонки

| Колонка CSV | Поле `Task` | Тип | Обязательность | Ограничения |
|---|---|---|---|---|
| `Приоритет` | `priority` | enum | Нет | `Critical`, `High`, `Medium`, `Low`; пусто → `Medium` |
| `Story points` | `initialStoryPoints` | number | Нет | Пусто или значение из шкалы SP |
| `Комментарии` | `notes` | text | Нет | До 5 000 символов; пусто → `null` |
| `Теги` | `tags` | string[] | Нет | До 10 тегов, каждый 1–50 символов |
| `Оценка после окончания работы` | `finalStoryPoints` | number | Нет | Пусто или значение из шкалы SP |

### 3.3. Справочники

**Компоненты:**

- `API`
- `WEB`

**Задетые сценарии:**

- `ЗАКАЗ`
- `ВВОД`

**Шкала Story Points:**

- `0`
- `0.5`
- `1`
- `2`
- `3`
- `5`
- `8`
- `13`
- `20`
- `40`
- `100`

## 4. Правила нормализации

- Пробелы в начале и конце значений удаляются.
- Пустая строка или строка из пробелов считается пустым значением.
- Для `Компоненты`, `Задетые сценарии` и `Теги` значения разделяются символом `;`.
- Пустые элементы после разделения удаляются.
- Регистр значений справочников нормализуется:
  - `api` → `API`;
  - `web` → `WEB`;
  - `заказ` → `ЗАКАЗ`;
  - `ввод` → `ВВОД`.
- Значение `Приоритет` нормализуется без учёта регистра.
- Неизвестные значения справочников не преобразуются автоматически, а помечаются как ошибка строки.

## 5. Валидация

### 5.1. Ошибки уровня файла

Импорт блокируется полностью, если:

- файл не читается;
- файл пустой;
- файл содержит только заголовки;
- кодировка не UTF-8;
- отсутствует хотя бы одна обязательная колонка;
- структура CSV некорректна и файл не может быть разобран;
- количество задач превышает лимит;
- размер файла превышает лимит;
- все строки содержат ошибки.

### 5.2. Ошибки уровня строки

| Ситуация | Тип реакции |
|---|---|
| Пустой `ID задачи` | Ошибка строки |
| Дубликат `ID задачи` в файле | Ошибка строки |
| Пустой `Заголовок` | Ошибка строки |
| Пустое `Описание` | Ошибка строки |
| Некорректный `Ссылка YouTrack` | Ошибка строки |
| Неизвестный `Приоритет` | Ошибка строки |
| Некорректное `Story points` | Ошибка строки |
| Пустое `Компоненты` | Ошибка строки |
| Неизвестный компонент | Ошибка строки |
| Пустое `Задетые сценарии` | Ошибка строки |
| Неизвестный сценарий | Ошибка строки |
| Превышен лимит символов | Ошибка строки |
| Лишняя колонка | Предупреждение, если обязательные колонки присутствуют |
| Отсутствует необязательная колонка | Предупреждение |

Для каждой ошибочной строки необходимо отображать:

- номер строки в исходном файле;
- название поля;
- полученное значение;
- текст ошибки.

## 6. Стратегия обработки ошибок

Для первой версии используется **выборочный импорт с явным подтверждением**.

### 6.1. Правила

1. Сервис разбирает весь файл.
2. В предпросмотре отображаются корректные и ошибочные строки.
3. Host может импортировать только корректные строки.
4. Ошибочные строки не добавляются в очередь.
5. Host видит количество корректных и ошибочных задач.
6. Если есть хотя бы одна корректная задача, доступен импорт.
7. Если корректных задач нет, импорт недоступен.
8. Отмена импорта не изменяет текущую очередь задач.

### 6.2. Состояния предпросмотра

| Состояние | Условие | Действие |
|---|---|---|
| Все строки корректны | Ошибок нет | Кнопка «Импортировать N задач» |
| Есть ошибки | Есть корректные и ошибочные строки | Кнопка «Импортировать N корректных задач» |
| Все строки с ошибками | Корректных строк нет | Импорт недоступен |
| Файл невалиден | Ошибка уровня файла | Импорт недоступен, показывается общая ошибка |

## 7. Маппинг YouTrack

| Поле YouTrack | Поле CSV | Поле `Task` | Правило |
|---|---|---|---|
| `ID задачи` | `ID задачи` | `externalId` | Без изменений |
| `Заголовок` | `Заголовок` | `title` | Trim |
| `Описание` | `Описание` | `description` | Trim |
| `Приоритет` | `Приоритет` | `priority` | Нормализация и проверка справочника |
| `Story points` | `Story points` | `initialStoryPoints` | Пусто или валидное значение шкалы |
| `Теги` | `Теги` | `tags` | Разделение по `;`, trim, удаление пустых |
| — | `Компоненты` | `components` | Может отсутствовать в стандартном экспорте; требуется ручное заполнение |
| — | `Задетые сценарии` | `affectedScenarios` | Может отсутствовать в стандартном экспорте; требуется ручное заполнение |
| — | `Ссылка YouTrack` | `youtrackUrl` | Если URL отсутствует, может быть сформирован из базового URL YouTrack и `ID задачи`; правило согласовать |

## 10. Тексты ошибок

| Ситуация | Текст |
|---|---|
| Общая ошибка разбора | «Не удалось распарсить файл. Проверьте формат.» |
| Пустой файл | «Файл пустой или не содержит задач.» |
| Нет обязательной колонки | «Отсутствует обязательная колонка: {название}.» |
| Пустое обязательное поле | «Строка {N}: не заполнено обязательное поле „{название}“.» |
| Неизвестный компонент | «Строка {N}: указан недопустимый компонент „{значение}“.» |
| Неизвестный сценарий | «Строка {N}: указан недопустимый сценарий „{значение}“.» |
| Некорректный URL | «Строка {N}: некорректная ссылка YouTrack.» |
| Некорректные SP | «Строка {N}: значение Story points должно быть из шкалы оценки.» |
| Дубликат ID | «Строка {N}: задача с ID „{ID}“ уже встречается в файле.» |
| Итог предпросмотра | «Готово к импорту: {N}. Задач с ошибками: {M}.» |
