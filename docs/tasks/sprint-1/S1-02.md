# ТЗ: S1-02 · Импорт задач из CSV с предпросмотром и подтверждением

**Статус:** рабочее ТЗ для разработки  
**Спринт:** 1 — «Скелет продукта»  
**Целевой уровень:** L2 — минимально работающая функция  
**Перенос:** Нет — без настоящего импорта задача спринта не достигнута  
**Ответственный за продуктовые решения:** тимлид (PM/PO)  
**Ответственные за реализацию:** тимлид и разработчики  

## 1. Основная идея

Host загружает один CSV-файл, самостоятельно определяет назначение колонок, видит результат проверки всех строк и предпросмотр корректных задач. После подтверждения импортируются все корректные строки в серверную очередь сессии; некорректные строки не попадают в очередь и отображаются с номером строки и причиной ошибки.

Отмена импорта не изменяет очередь. На уровне S1-02 не требуется поддержка Excel, прямого YouTrack API, редактирования строк в предпросмотре и импорта второго файла.

## 2. Пользовательский сценарий

1. Host находится в лобби созданной сессии.
2. Host выбирает CSV-файл на своём устройстве.
3. Система считывает файл и показывает форму сопоставления колонок.
4. Host указывает, какая колонка содержит ID задачи, заголовок и колонку для будущей записи итоговых SP.
5. Система проверяет все строки файла и показывает результат проверки.
6. Host видит предпросмотр корректных задач.
7. Если есть некорректные строки, Host видит их номера и причины ошибок.
8. Host подтверждает импорт корректных задач.
9. Система сохраняет корректные задачи в серверную очередь сессии.
10. Host возвращается в лобби и видит обновлённую очередь.
11. Если Host отменяет импорт, очередь сессии не изменяется.

## 3. Требования к поведению

### 3.1. Загрузка файла

- Host может выбрать один CSV-файл для импорта.
- Система должна проверять, что выбран файл имеет поддерживаемый формат CSV.
- Если файл не выбран, система не должна начинать импорт.
- Если файл повреждён, пустой или не может быть прочитан, Host должен увидеть понятное сообщение об ошибке.
- До подтверждения импорта выбранный файл не должен изменять очередь сессии.

### 3.2. Сопоставление колонок

- Host самостоятельно определяет назначение колонок CSV.
- Обязательно должны быть указаны:
  - колонка с ID задачи;
  - колонка с заголовком задачи;
  - колонка для будущей записи итоговых SP.
- Названия колонок в файле могут быть произвольными.
- Описание задачи, ссылка YouTrack и дополнительные характеристики являются необязательными.
- Если Host не указал обязательные колонки, система не должна разрешать подтверждение импорта.
- Если обязательная колонка не найдена или выбрана повторно, система должна показать понятное сообщение об ошибке.
- Если в CSV нет колонки для итоговых SP, приложение должно показать подсказку, но не создавать колонку самостоятельно.
- В этом случае Host должен добавить колонку в конец файла вручную и загрузить CSV повторно.

### 3.3. Проверка и предпросмотр

- Система должна проверить все строки CSV до подтверждения импорта.
- Host должен видеть предпросмотр корректных задач.
- Host должен видеть количество корректных и некорректных строк.
- Для каждой некорректной строки система должна показывать:
  - номер строки в исходном файле;
  - причину ошибки.
- Некорректные строки не должны попадать в очередь при подтверждении импорта.
- Корректные строки должны быть доступны для просмотра до подтверждения.
- Редактирование содержимого строк в предпросмотре в S1-02 не требуется.

### 3.4. Подтверждение импорта

- Host может подтвердить импорт только после успешной проверки файла и указания обязательных колонок.
- После подтверждения все корректные строки должны быть сохранены в серверную очередь сессии.
- После успешного импорта Host должен увидеть обновлённую очередь в лобби.
- Если в файле есть некорректные строки, они не должны быть добавлены в очередь.
- Если в файле нет ни одной корректной строки, система не должна добавлять задачи в очередь и должна показать понятное сообщение.

### 3.5. Отмена импорта

- Host может отменить импорт до подтверждения.
- После отмены очередь сессии должна остаться без изменений.
- После отмены Host должен вернуться к состоянию, в котором может повторить импорт или отказаться от него.

### 3.6. Повторный импорт

- Host может повторить импорт после отмены или после ошибки.
- Повторный импорт должен работать с новым либо повторно загруженным CSV-файлом.
- В S1-02 не требуется поддержка одновременного импорта нескольких файлов.
- Поведение при повторном импорте задач с теми же ID должно быть согласовано отдельно.

## 4. Обязательные данные

Для каждой корректной задачи должны быть доступны как минимум:

- ID задачи.
- Заголовок задачи.
- Колонка для будущей записи итоговых SP.

Необязательные данные:

- Описание задачи.
- Ссылка YouTrack.
- Дополнительные характеристики задачи.

При импорте старые значения в колонке итоговых SP игнорируются. Перед подтверждением импорта система должна предупреждать Host, что после последующей оценки значения в этой колонке будут заменены новыми итоговыми SP.

## 5. Ограничения и правила

- Поддерживается только один CSV-файл за одну операцию импорта.
- Не требуется поддержка Excel.
- Не требуется прямое подключение к YouTrack.
- Не требуется редактирование строк в предпросмотре.
- Не требуется автоматическое создание отсутствующей колонки для итоговых SP.
- Не требуется импорт второго файла в рамках одной операции.
- Не требуется расширенная валидация содержимого задач, если базовые обязательные поля корректны.
- Не требуется управление очередью: добавление, удаление, перестановка и пропуск задач остаются вне S1-02.
- Предельный размер CSV и допустимое число задач — открытый вопрос.

## 6. Ошибки и состояния

### 6.1. Ошибки файла

- Если файл не выбран, отображается сообщение: «Выберите CSV-файл».
- Если файл не является CSV или не может быть прочитан, отображается сообщение: «Не удалось прочитать файл. Проверьте формат CSV».
- Если файл пустой, отображается сообщение: «Файл не содержит задач».
- Если файл превышает согласованный лимит, отображается сообщение о превышении размера или количества задач.

### 6.2. Ошибки сопоставления

- Если не указана обязательная колонка, отображается сообщение: «Укажите колонку для [название поля]».
- Если одна и та же колонка выбрана для нескольких обязательных полей, отображается сообщение: «Выберите разные колонки для обязательных полей».
- Если в CSV нет колонки для итоговых SP, отображается подсказка: «Добавьте колонку для итоговых SP в конец файла и загрузите CSV повторно».

### 6.3. Ошибки строк

- Если обязательное поле строки пустое, отображается сообщение: «Строка N: не заполнено обязательное поле [название поля]».
- Если ID задачи отсутствует или некорректен, отображается сообщение: «Строка N: некорректный ID задачи».
- Если заголовок задачи отсутствует, отображается сообщение: «Строка N: не заполнен заголовок задачи».

### 6.4. Ошибки сохранения

- Если сервер не смог сохранить корректные задачи, Host должен увидеть понятное сообщение об ошибке.
- После ошибки сохранения очередь не должна содержать частично добавленные задачи без явного указания на это.
- Host должен иметь возможность повторить импорт.

## 7. Критерии приёмки

### AC-1. Успешный импорт корректного CSV

**Дано:** Host находится в лобби сессии и имеет корректный CSV-файл.  
**Когда:** Host загружает файл, указывает обязательные колонки и подтверждает импорт.  
**Тогда:** все корректные строки сохраняются в серверной очереди сессии и отображаются в лобби.

### AC-2. Предпросмотр до подтверждения

**Дано:** Host загрузил CSV и указал обязательные колонки.  
**Когда:** система завершила проверку файла.  
**Тогда:** Host видит предпросмотр корректных задач до их добавления в очередь.

### AC-3. Некорректные строки не импортируются

**Дано:** CSV содержит корректные и некорректные строки.  
**Когда:** Host подтверждает импорт.  
**Тогда:** в очередь добавляются только корректные строки, а для некорректных отображаются номер строки и причина ошибки.

### AC-4. Отмена не меняет очередь

**Дано:** Host загрузил CSV и видит предпросмотр.  
**Когда:** Host отменяет импорт.  
**Тогда:** очередь сессии остаётся без изменений.

### AC-5. Обязательные колонки не выбраны

**Дано:** Host загрузил CSV, но не указал все обязательные колонки.  
**Когда:** Host пытается подтвердить импорт.  
**Тогда:** система показывает понятное сообщение об ошибке и не добавляет задачи в очередь.

### AC-6. Нет колонки для итоговых SP

**Дано:** CSV не содержит колонку для будущей записи итоговых SP.  
**Когда:** Host загружает файл.  
**Тогда:** система показывает подсказку о необходимости добавить колонку вручную и повторно загрузить CSV.

### AC-7. Ошибка файла

**Дано:** Host выбрал пустой, повреждённый или неподдерживаемый файл.  
**Когда:** система пытается обработать файл.  
**Тогда:** отображается понятное сообщение об ошибке, а очередь сессии не изменяется.

### AC-8. Сохранение после импорта

**Дано:** Host успешно импортировал корректные задачи.  
**Когда:** Host обновляет страницу или повторно открывает сессию.  
**Тогда:** импортированные задачи остаются в очереди.

## 8. Предлагаемый вариант интерфейса

Этот раздел — предложение для согласования, а не обязательное техническое решение.

### 8.1. Модальное окно импорта

- Заголовок: «Импорт задач из CSV».
- Зона выбора или перетаскивания CSV-файла.
- Кнопка «Выбрать файл».
- Блок сопоставления колонок.
- Список обязательных полей:
  - ID задачи;
  - Заголовок задачи;
  - Колонка для итоговых SP.
- Список необязательных полей:
  - Описание;
  - Ссылка YouTrack;
  - Дополнительные характеристики.
- Кнопка «Проверить файл».
- Кнопка «Импортировать N задач».
- Кнопка «Отмена».

### 8.2. Предпросмотр

- Счётчик корректных задач.
- Счётчик некорректных задач.
- Таблица предпросмотра корректных задач.
- Список ошибок с номером строки и причиной.
- Предупреждение о замене старых значений в колонке итоговых SP после оценки.
- Подсказка при отсутствии колонки для итоговых SP.

### 8.3. Лобби после импорта

- Обновлённый список задач в очереди.
- Количество импортированных задач.
- Пустое состояние, если ни одна задача не была импортирована.

## 9. Предлагаемый технический вариант

Этот раздел не является обязательным техническим решением. Разработчики вправе выбрать собственную реализацию, если она удовлетворяет требованиям и критериям приёмки.

- Файл может загружаться на сервер для проверки и последующего сохранения задач.
- Сопоставление колонок может выполняться на клиенте либо на сервере; выбор способа остаётся инженерным решением.
- Проверка строк может быть выполнена до сохранения, чтобы некорректные строки не попадали в очередь.
- После подтверждения сервер может сохранить только корректные задачи и вернуть обновлённое состояние очереди.
- Для идентификации строк в ошибках может использоваться номер строки исходного CSV-файла.
- Для повторного доступа к очереди может использоваться уже созданный в S1-01 идентификатор сессии.

## 12. Что не входит в S1-02

- Подключение Participant по коду или ссылке.
- Добавление задачи вручную.
- Удаление, перестановка и пропуск задач.
- Просмотр и оценка текущей задачи.
- Выбор и подтверждение итогового SP.
- Экран итогов сессии.
- Экспорт CSV, Excel и интеграция с YouTrack.
- Таймер, комментарии, исторические эталоны и расширенная статистика.
- Управление ролями, завершение сессии и удаление сессии.
